How to play
  • Fill the empty cells with 1–9. Each row, column and bold-outlined 3×3 box must contain every number exactly once.
  • Tap a cell, then a number below. On a computer you can also use 1–9, the arrow keys and Backspace.
  • Not sure? Turn on ✏️ Notes and jot down the numbers that could fit. (Shortcut: N)
  • 💡 Hint fills the next solvable cell and explains why. If you have a wrong number, it points that out first. (Shortcut: H)
  • The small number under each button shows how many more of that number are needed.
  • The Daily puzzle changes every day and is the same for everyone. Solve it daily to build a 🔥 streak.
  • Practice gives you a fresh puzzle every time you press "New puzzle", including an Expert level.
  • Every puzzle has exactly one solution. Your game is saved automatically.

How to enjoy Sudoku

Sudoku is a puzzle where you fill the empty cells of a 9×9 grid with the numbers 1 to 9. No arithmetic is needed; it is pure logic. On WowEzBox, Daily gives you a new puzzle every day, the same for everyone that day, and Practice lets you solve as many puzzles as you like at the level you choose.

Where to start

  1. Look first at rows and boxes that are nearly full; the fewer empty cells, the sooner the answer shows.
  2. Pick one number (say 1) and look for where it can go across the whole grid. Work through 1 to 9.
  3. When stuck, turn on ✏️ Notes and jot the possible numbers in each cell. [Fill in all candidates] does it in one go.
  4. Still stuck? Press 💡 Hint. It shows the next cell and explains why that number goes there.

Basic techniques

  • Naked single: if only one number can go in a cell, that's the answer.
  • Hidden single: if a number fits in only one cell of a row, column or box, it goes there.
  • Box-line interaction: if, inside a box, a number's candidates all lie on one line, you can remove that number from the same line in the other boxes.
  • Naked pair: if two cells in a row have the same two candidates and nothing else, those two numbers belong to those cells, so remove them from the rest of the row.
  • X-Wing: for harder puzzles. If in two rows a number's candidates sit in the same two columns only, you can remove that number from the other cells of those columns.

Levels are set by the techniques a puzzle needs: Easy can be solved with the first two, and higher levels need the later ones.

FAQ

Will I ever have to guess?
No. Every puzzle has exactly one solution, so it can be solved by logic alone.
Is there a time limit?
No. The time is only recorded. Press ⏸ to pause whenever you need a break.
When does the daily puzzle change?
A new puzzle appears when the date changes. Solve it every day to build your 🔥 streak.
